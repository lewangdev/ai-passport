# 牛马歌子实现与验收清单

目标是完整的职场电子宠物游戏，而不是一组可点击页面。
当前分支为 `feature/niuma-gezi`。未经单独请求，不烧录、不发布。
保持基线受保护的 Flash 布局。

## 已确定的体验

- 240 x 320 竖屏、四色复古像素 UI、实体上/下/确定三键。
- 男性参考形象：宽方脸、平下巴、大头、短西装躯干与短腿。
  女性：独立的圆润短鹅蛋脸、高马尾、西装外套与长裤。
  男女角色玩法能力与身体比例相同。
- 入职、办公、倦怠、离职、重新入职五种姿态，以及吃饭、休息、
  锻炼、学习、社交和整理等反馈。
- 每模拟日六格行动，每周五工作日与两周末日；离线不恶化、不惩罚，
  存档恢复当天进度。
- 饱腹、精力、心情、压力、健康；职业经验与当日绩效分离，收入、支出、
  日净收益应能对账。
- 工作、加班、喂食、咖啡、白水、免费基础餐、做饭、休息、摸鱼、
  三类学习、锻炼、清理、如厕、治疗、免费休养、聊天、赠礼。
  确认前预览效果。
- 六个真实可交互小游戏：键盘轨道与时机、会议回应、通勤抢座、
  茶水间警戒、接便当、电梯/楼梯下班路线。
  跳过保留基础行动收益，额外奖励只结算一次；静音仍可识别游戏提示。
- 每日选择事件、关系门槛、季度考核、首次失败而后可以成功的谈薪、
  可恢复的倦怠、离职、三类公司、再入职和可继续游玩的里程碑。
- 根据近期行动形成六种可变风格、三段关系、工位/家居/服装商店、
  背包、装饰预览、成就与有日期的回忆；没有付费随机抽取或永久死亡。
- 启动/创建/命名/工牌/帮助，办公室/家/周末，行动菜单与结果，事件，
  六小游戏，工资条，资料/成长/风格，离职/公司，商店/物品/背包/装扮，
  纪念册，以及全部设置页面。
- 音量、按键音、可选原创轻柔办公室背景音乐、亮度、闲置息屏、
  中英双语、电量未知/低电量、保存失败/重试、余额不足兜底、
  行动耗尽提示和二次确认重置。不沿用此前其他应用的音乐要求。

## 运行架构

规则、小游戏计时和存档编码独立于 LVGL/ESP-IDF。
UI 单一所有者处理按键队列；回调不写音频或 NVS。
存储与音频任务接收快照或消息。不访问已经删除的 UI 对象，
非所属任务访问 LVGL 必须持锁。息屏暂停游戏时间，唤醒按键被消费，
不能误触发游戏行动。

## 职业去向规则

每天使用行动格之前可以切换，晚间不能切换。技能、收藏及首次进入日期保留。
此时随时可以切回普通职场；入职新公司会重置当前路线。

| 去向 | 进入条件 | 持续效果 |
| --- | --- | --- |
| 技术专家 | 在职、专业 120、经验 240 | 每格工作额外经验 +6 |
| 团队管理 | 在职、沟通 120、前辈关系 60 | 每格工作后全部三位朋友关系 +1 |
| 自由职业 | 已离职、专业 96、存款 100 | 每格工作收入 12，无底薪和加班 |
| 经营小店 | 已离职、生活 96、存款 200 | 每格工作收入 10，无底薪和加班 |
| 舒适生活 | 准点下班 10 次、生活 48 | 休息/散步额外心情 +5、压力 -5 |

存款条件是储备金门槛，不是购买价格。自由职业和小店保留五天工作、两天周末
的节奏，在结束工作时仅结算一次收入。
