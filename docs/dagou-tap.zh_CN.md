# 口袋大狗 Tap

把[马克杯 MarkCup 的大狗 Tap](https://www.bilibili.com/toy/Dagou-Tap/index.html)适配到 AI Passport 的独立离线应用。界面为简体中文，音名保留拉丁字母。开机先向收礼的朋友问好，按任意键开始。

## 操作

| 场景 | 上键 | 下键 | 确定键 |
| --- | --- | --- | --- |
| 普通演奏 | 大 / 哈 | 狗 / 基 | 叫 / 米 |
| 普通模式长按 | 下一档音高 | 进入设置 | 元音延音、膨胀抖动 |
| 钢琴模式 | 下一个白键音 | 上一个白键音 | 演奏选定的音节与音高 |
| 钢琴模式长按 | 启用八度切换时跳到下一八度 | 进入设置 | 选定第三音节时延音 |
| 设置列表 | 上一项 | 下一项 | 进入或结束调整 |
| 调整数值 | 减小或切换 | 增大或切换 | 完成调整 |

长按下键也可关闭设置。钢琴模式可在设置里选择音节，从而访问全部 24 种音节与音高组合。三个电阻分压按键不支持多点触控或同时按和弦。普通模式的长按被识别之前会先发出一次声音。延音最多 15 秒，避免按键事件丢失后一直发声。

## 与网页对照

| 原作 | 硬件适配 |
| --- | --- |
| 三个音节、四档音高 | 两组默认原声采样，相同的目标 MIDI 音高；长按上键或在设置中换档 |
| 八个白键音，起始八度 C3–C6 | 相同大调音阶和八度范围，实体按键选择 |
| WSOLA 元音延音纹理 | 带交叉淡化的短采样循环与松手渐弱，属于节省内存的近似实现 |
| 128 BPM、C–G–Am–F 伴奏 | 本地合成底鼓、军鼓、踩镲、贝斯及琶音；节奏接近，不是完全相同的 Web Audio 混音 |
| 八分音符节奏吸附 | 使用音频采样时钟调度，可关闭；吸附最多有约 234 毫秒的预期等待 |
| 张嘴、弹跳、膨胀、变红、抖动 | 默认角色张闭嘴图、跟拍弹跳、长按缩放染色抖动 |
| 十二种几何特效 | 十二类轻量特效，复用固定数量对象，简化形状与运动 |
| 音乐/音效开关、钢琴、八度、吸附、网格 | 本地设置，额外提供音量、亮度、音高档位、音节和恢复默认 |
| 哔哩哔哩云设置 | 本地 NVS 保存，版本及范围检查、延迟写入、显示保存状态 |
| 投币解锁叮咚鸡和帝皇形象 | 保留锁定说明，不绕过授权或打包受限素材 |
| 作者主页、视频跳转 | 关于页面保留作者署名，本说明提供原作链接 |

屏幕显示音量和电量；电量不可读时显示 `--`。设置页继续播放背景音乐。音频失败会显示提示，视觉交互仍可使用。这是个人本地适配，不是原作者的官方发布。

## 素材与实现

`assets/dagou-tap/` 包含四张 132 × 152 BGRA 图，以及六段 16 kHz、16 位有符号单声道采样，总计约 375 KiB。素材嵌入 Flash，不将完整音频或图像复制进 RAM。原网页的默认公开素材不适用本仓库的 MIT 协议，目前未找到再分发许可；公开发布素材或含素材的固件之前应获得作者许可。

运行 `tools/prepare_dagou_assets.py /path/to/downloads` 可用 ffmpeg 重现转换。输入为公开的 `audio-data.js` 及四张 PNG：`dagou_close.png`、`dagou_open.png`、`cat_close.png`、`cat_open.png`。只提取默认的大/狗/叫和哈/基/米音效。研究的网页版本为 `12420391163904-v7471`，主脚本版本为 `20260817-coin-errors`。

UI 定时器独占 LVGL 操作，按键回调仅发送事件。专门任务处理混音，另一个任务处理 NVS 与电量读取，避免阻塞采样生成。任务与界面对象随整个应用存活，没有反复进入、删除页面的竞争。分区协议保持不变：应用上限 3 MB，`cardid` 固定在 `0x356000`，Recovery 固定在 `0x700000`。

## 验证

中文 UI 使用思源黑体 SC Regular 生成的 144 字形子集，遵循 SIL OFL，
许可见 `assets/fonts/dagou-font-LICENSE.txt`。重新生成命令：
`python3 tools/prepare_dagou_font.py /path/to/lv_font_conv.js /path/to/SourceHanSansSC-Regular.otf`。
LVGL 内存池为 48 KiB。桌面渲染测试运行真正的界面代码，遍历全部设置、
连续触发音符，测得 UI 峰值占用约 26.6 KB（主机内存开销与 ESP32 不同）。

依赖已下载后，可以重现视觉检查：

```bash
cmake -S tests/dagou_render -B /tmp/dagou-render-build -G Ninja
cmake --build /tmp/dagou-render-build
/tmp/dagou-render-build/dagou_render
```

从仓库根目录运行渲染程序，它生成五张 240 × 320 PPM 截图到
`/tmp/dagou-*.ppm`，并检查设置排版与 LVGL 内存完整性。
硬件与音频接口使用模拟实现，不能代替真实屏幕或 I2S 时序测试。

在 ESP-IDF 5.5.3 环境运行 `./tools/validate.sh`。主机测试覆盖音高表、八度边界、无效设置、循环选择和节奏量化；完整固件检查验证镜像与保护区域。

实机需要检查持续声音无明显点击或断音、三个按键与长按、音高及八度范围、关机后设置恢复、文字清晰、动画稳定、音量亮度调节与合理的电量读数。编译通过不代表这些硬件项目已通过。
